# SigmaOS accelerate

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-accelerate`.

Despite the crate description, no cloud, machine-learning, blockchain, or acceleration implementation is present in the source.

## Build

```sh
cargo check --lib
```
